Shared trips are automatic. Guests who get your shared-trips link see every open date. The first booking on a date opens Jeep 1; when it is full, Jeep 2 opens, and so on while you have jeeps free. A jeep goes ahead once ${SETTINGS.minSeats} seats are paid (the dashboard flags it once that many are booked). If not, it auto-cancels ${SETTINGS.payWindowH}h before start and refunds everyone. You can still create a trip by hand with + Create trip.
